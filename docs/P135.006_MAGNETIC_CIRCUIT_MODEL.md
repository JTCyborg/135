# P135.006 — Nonlinear magnetic circuit model

## Scope (D45)

The domain library now provides a bounded, single-winding nonlinear magnetic-circuit solver using a supplied measured/manufacturer B-H curve and a lumped air gap.

API: p135/domain/magnetic_circuit.hpp: MagneticCircuitRequest, MagneticCircuitResult, analyzeMagneticCircuit().

Input: effective core area Ae, mean magnetic path le, total physical air gap lg, turn count N, absolute current magnitude, validated CoreMaterial::bhCurve.

Output: B, Hcore, Hgap, flux Φ, secant inductance Lsec, differential inductance Ldiff, optional knee B/current/utilization, and explicit B-H-range status.

## Equations

The operating point is found from the nonlinear Ampere law:

NI = Hcore(B) · le + B · lg / μ0

The measured B-H curve is piecewise-linearly interpolated. Above the final measured point, the solver continues with the vacuum-permeability asymptote dH/dB = 1/μ0. The result sets withinBhCurveRange=false whenever this continuation is used; extrapolated values are numerical estimates, not measured material data.

Flux and inductance:
- Φ = B · Ae
- Lsec = N · Φ / I (zero at zero current)
- Ldiff = N² / (le/(Ae · dH/dB) + lg/(μ0 · Ae))

The gap field is Hgap = B/μ0. The supplied effective area is used directly; no gap-fringing correction is applied.

## Knee criterion

A knee candidate is the first B-H segment whose dH/dB reaches or exceeds the initial segment slope divided by kneeSlopeRatio (default 0.2, i.e. five times the initial slope). The returned knee B is the preceding measured point and knee current is calculated from the magnetic-circuit MMF equation.

This is a declared numerical knee criterion, not a universal material Bsat. The criterion and B-H sampling density must be reviewed for each material. If the curve contains no qualifying segment, knee values remain absent / NOT_VERIFIED.

## Explicit limitations

- Single lumped magnetic path and one winding; no coupled multi-leg/three-phase magnetic network.
- Uniform core flux; no fringing, leakage, joints, local saturation or corner effects.
- No hysteresis/minor loops, remanence, coercivity, frequency dependence, dynamic losses or temperature correction.
- No winding resistance, copper loss, thermal feedback or transient waveform integration.
- The B-H curve must start at (H=0, B=0) and be monotonic. Beyond its last measured point, the solver uses the explicitly flagged μ0 differential-permeability asymptote.
- CoreLossPoint data is not yet integrated into this solver.
- The model does not infer a manufacturer's DC-bias Isat from the knee criterion. These are different definitions and must remain separate.

## Verification

Project135DomainTests exercises a synthetic monotonic B-H curve, nonzero air gap, solved operating point, flux, secant/differential inductance, knee current, invalid input and explicit out-of-range rejection.

The synthetic fixture is for numerical regression only, not a manufacturer's material dataset or a design-release validation.

## Desktop integration (D46)

The Advanced section of the shunt-filter calculation accepts per-phase equivalent core geometry (Ae in mm², le and total gap in mm), turns, a provenance reference and a B-H table (H [A/m], B [T], one point per line; comma, semicolon or whitespace separators). The input is explicitly user-supplied and is stored with the immutable calculation snapshot.

For every frequency point in the existing AC sweep, the maximum of the three phase branch RMS currents is converted to peak current (√2 × max phase RMS) and passed to the magnetic-circuit solver. The resulting peak flux density B(f) is stored in the snapshot. If any sweep point leaves the measured B-H range, the complete B(f) series is withheld and marked NOT_VERIFIED; no extrapolated segments are plotted.

The results table also reports the maximum phase peak current over the sweep and percentage margins to the B-H knee current and the entered manufacturer Isat reference. A positive margin means the sweep peak is below the reference; a negative margin means it exceeds it. The manufacturer-reference margin remains evidence-unverified until the source is supplied and independently reviewed.

The current-frequency chart distinguishes two separate references:
- Red dashed: user-entered manufacturer peak-current reference, only comparable when the datasheet defines the same peak-current basis.
- Purple dash-dot: B-H knee current calculated from the supplied geometry and the declared dH/dB slope criterion.

The knee reference is probed at zero current, so it remains available even when a high-current sweep point exceeds the measured B-H range. This does not make the out-of-range B(f) values valid. The graph is an equivalent single magnetic path per phase, not a coupled three-limb core solution.


## Coupled three-limb reluctance network (D47)

A second domain API, `analyzeThreeLimbMagneticCircuit()`, models a symmetric three-limb core as a nonlinear magnetic network with six magnetic-potential nodes and seven reluctance branches:
- Three wound limbs (A, B, C), each with its own turn count and instantaneous phase current.
- Two inter-limb yoke segments at the top and two at the bottom.
- Each limb has its own air-gap term; yokes are modelled without a gap in this version.

The nodal solver enforces flux continuity at all six nodes. Each branch uses the same measured positive B-H curve; negative flux is represented by odd symmetry. A damped Newton method solves the five independent node potentials with one gauge node fixed. No branch may leave the measured B-H domain and no extrapolation is performed. The result includes signed limb/yoke fluxes and flux densities, node magnetic potentials, iteration count and maximum flux-continuity residual.

The desktop shunt-filter workflow accepts separate limb and yoke effective areas and path lengths. For every frequency point it samples 72 equally spaced instants of the three AC phase-current phasors, solves the coupled magnetic network at each instant, and plots the maximum absolute B reached in each limb and yoke segment over the sampled cycle. The frequency sweep and per-frequency peak B values are persisted in the immutable calculation snapshot together with the yoke geometry.

This is a first-order symmetric 3-limb reluctance network, not a full field solution. The current topology assumes equal limb geometry, equal turns, a symmetric material curve, equal air gaps and two equal-length yoke segments per level. It does not model joints, corner leakage, local flux crowding, fringing, hysteresis, remanence, eddy-current loss, temperature-dependent B-H data, phase asymmetry or transient DC offset. The 72-point time sampling is a numerical sampling choice and is not a rigorous bound on narrow waveform peaks. FEM comparison remains required before design release.


## Harmonic operating-point magnetic analysis (D48)

The harmonic filter solver now retains complex phase-A/B/C current phasors for every filter branch and harmonic order. Positive- and negative-sequence phase rotation is applied explicitly; Delta branch currents include the line-to-line voltage magnitude and sequence-dependent 30-degree displacement.

The coupled three-limb cycle sampler accepts a list of harmonic excitations. It reconstructs the instantaneous winding current over one fundamental cycle as the sum of all supplied harmonic RMS phasors (converted to peak values), plus the configured per-phase DC bias. The desktop calculation sums branch-current phasors at each harmonic and runs this operating-point calculation independently of the frequency-response sweep.

The result reports peak absolute flux density for limbs A/B/C and all four yoke segments, adaptive sample count, successive-grid peak change, and whether every sampled branch remained inside the measured B-H curve. When the solver uses the documented μ0 differential-permeability continuation beyond the final measured point, numerical values are retained but explicitly marked EXTRAPOLATED_NOT_VERIFIED. The independent frequency sweep remains a diagnostic response study and must not be interpreted as the normal operating waveform.

The operating-point current waveform assumes integer harmonic orders referenced to the fundamental and steady-state periodic operation. It does not model interharmonics, switching transients, remanence, hysteresis/minor loops, DC offset beyond the entered per-phase bias, or thermal coupling. Core temperature rise is not calculated by this magnetic operating-point solver; a separate validated core-loss and thermal network with winding resistance and thermal boundary data is required.
