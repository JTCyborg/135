# P135.006 — Nonlinear magnetic circuit model

## Scope (D45)

The domain library now provides a bounded, single-winding nonlinear magnetic-circuit solver using a supplied measured/manufacturer B-H curve and a lumped air gap.

API: p135/domain/magnetic_circuit.hpp: MagneticCircuitRequest, MagneticCircuitResult, analyzeMagneticCircuit().

Input: effective core area Ae, mean magnetic path le, total physical air gap lg, turn count N, absolute current magnitude, validated CoreMaterial::bhCurve.

Output: B, Hcore, Hgap, flux Φ, secant inductance Lsec, differential inductance Ldiff, optional knee B/current/utilization, and explicit B-H-range status.

## Equations

The operating point is found from the nonlinear Ampere law:

NI = Hcore(B) · le + B · lg / μ0

The measured B-H curve is piecewise-linearly interpolated. A 100-iteration bisection solves for B. The solver refuses to extrapolate beyond the final measured B-H point and returns ModelOutOfDomain.

Flux and inductance:
- Φ = B · Ae
- Lsec = N · Φ / I (zero at zero current)
- Ldiff = N² / (le/(Ae · dH/dB) + lg/(μ0 · Ae))

The gap field is Hgap = B/μ0. The supplied effective area is used directly; no gap-fringing correction is applied.

## Knee criterion

A knee candidate is the first B-H segment whose dH/dB reaches or exceeds the initial segment slope divided by kneeSlopeRatio (default 0.2, i.e. five times the initial slope). The returned knee B is the preceding measured point and knee current is calculated from the magnetic-circuit MMF equation.

This is a declared numerical knee criterion, not a universal material Bsat. The criterion and B-H sampling density must be reviewed for each material. If the curve contains no qualifying segment, knee values remain absent / NOT_VERIFIED.

## Explicit limitations

- Single lumped magnetic path and one winding; no coupled multi-leg/three-phase magnetic network.
- Uniform core flux; no fringing, leakage, joints, local saturation or corner effects.
- No hysteresis/minor loops, remanence, coercivity, frequency dependence, dynamic losses or temperature correction.
- No winding resistance, copper loss, thermal feedback or transient waveform integration.
- The B-H curve is assumed to start at (H=0, B=0), is monotonic and is never extrapolated.
- CoreLossPoint data is not yet integrated into this solver.
- The model does not infer a manufacturer's DC-bias Isat from the knee criterion. These are different definitions and must remain separate.

## Verification

Project135DomainTests exercises a synthetic monotonic B-H curve, nonzero air gap, solved operating point, flux, secant/differential inductance, knee current, invalid input and explicit out-of-range rejection.

The synthetic fixture is for numerical regression only, not a manufacturer's material dataset or a design-release validation.

## Desktop integration (D46)

The Advanced section of the shunt-filter calculation accepts per-phase equivalent core geometry (Ae in mm², le and total gap in mm), turns, a provenance reference and a B-H table (H [A/m], B [T], one point per line; comma, semicolon or whitespace separators). The input is explicitly user-supplied and is stored with the immutable calculation snapshot.

For every frequency point in the existing AC sweep, the maximum of the three phase branch RMS currents is converted to peak current (√2 × max phase RMS) and passed to the magnetic-circuit solver. The resulting peak flux density B(f) is stored in the snapshot. If any sweep point leaves the measured B-H range, the complete B(f) series is withheld and marked NOT_VERIFIED; no extrapolated segments are plotted.

The current-frequency chart distinguishes two separate references:
- Red dashed: user-entered manufacturer peak-current reference, only comparable when the datasheet defines the same peak-current basis.
- Purple dash-dot: B-H knee current calculated from the supplied geometry and the declared dH/dB slope criterion.

The knee reference is probed at zero current, so it remains available even when a high-current sweep point exceeds the measured B-H range. This does not make the out-of-range B(f) values valid. The graph is an equivalent single magnetic path per phase, not a coupled three-limb core solution.
