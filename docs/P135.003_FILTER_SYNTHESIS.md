# P135.003 — Shunt Passive Filter domain model and first synthesis

Status: analytical sizing, three-phase circuit generation, fundamental-frequency MNA verification, source/filter impedance scanning, and balanced positive-sequence harmonic response with THD and branch stress aggregation are implemented. Desktop integration and standards-based compliance remain pending.

## Scope implemented

The new `Project135Filter` library is independent from Qt and the desktop executable. It uses the shared SI quantity types and `Result<T>` diagnostics from Core.

The first supported product model is a three-phase shunt bank containing one or more parallel single-tuned series-RLC branches. Each branch specifies:

- unique branch ID and display name;
- tuning harmonic order (integer order, at least 2);
- total three-phase fundamental-frequency target reactive power in watts/var (SI power unit);
- series-branch quality factor used to derive the damping resistance.

The network specifies RMS line-to-line voltage, fundamental frequency, and Wye or Delta branch connection.

## Analytical sizing

For each branch, the target three-phase reactive power is divided equally among the three phases. Phase voltage is:

- Wye: U_phase = U_LL / sqrt(3)
- Delta: U_phase = U_LL

For tuning order h, fundamental angular frequency omega_1, tuning angular frequency omega_t = h * omega_1, and branch quality factor Q_f, the series resistance is included in the fundamental-frequency reactive-power sizing:

- X = (omega_t^2 - omega_1^2) / omega_1
- R = omega_t * L / Q_f
- L = U_phase^2 * X / (Q_phase * (X^2 + (omega_t / Q_f)^2))
- C = 1 / (omega_t^2 * L)

This sizing makes the requested fundamental-frequency reactive power consistent with the actual damped series-RLC branch. It remains a linear, ideal-component model: capacitor ESR/ESL, tolerances, temperature dependencies, switching transients, and standards compliance are not included.

## Validation

The synthesis API rejects non-finite/non-positive network voltage and frequency, an empty branch list, tuning orders below 2, non-positive/non-finite branch kvar or quality factor, duplicate branch IDs, and non-finite/non-positive calculated component values. Failures return `ErrorCode::InvalidInput` with a stable diagnostic code and field path.

No result is generated for invalid or unsupported input.

## Tests

The filter test target checks:

1. Wye phase-voltage conversion and 5th-harmonic C/L/R sizing against independent equations.
2. Delta phase voltage and relative capacitance.
3. Rejection of invalid tuning order, reactive power and quality factor.
4. Rejection of duplicate branch IDs and an empty bank.

## Three-phase circuit generation and MNA verification

The filter module now exposes `buildCircuit(FilterDesign)`, which creates a balanced ideal three-phase RMS phasor source and stamps each synthesized branch as a physical series R-L-C path. Wye branches connect phase-to-neutral; Delta branches connect L1-L2, L2-L3 and L3-L1. The generated network uses the existing Project135Circuit MNA solver; the filter module does not duplicate circuit-solving logic.

Regression tests cover generated topology and AC power at the fundamental frequency for Wye and Delta, plus operation at the 5th-harmonic tuning frequency. The desktop calculation now performs this AC MNA solve at the selected fundamental frequency and displays the passive-bank P/Q and solver residual.

The circuit is presently an ideal balanced-source model with no source impedance, feeder impedance, background harmonic voltage, capacitor ESR/ESL or component tolerances. Therefore it verifies internal consistency of the synthesized ideal LC bank; it is not a prediction of a specific installation's harmonic attenuation or compliance.


## Per-phase source/filter impedance scan

The filter module now exposes `analyzeFrequencyResponse(FrequencyResponseRequest)`. The request contains a synthesized filter design, a per-phase Thevenin source model (series resistance and inductance), scan limits, point count, and linear/logarithmic spacing.

At every frequency the analysis evaluates each series-RLC branch, combines the branches in parallel, combines the resulting filter impedance with the source impedance, and returns:
- filter-bank impedance magnitude;
- source impedance magnitude;
- bus driving-point impedance magnitude and phase;
- discrete local maxima of the bus impedance curve as candidate parallel-resonance peaks.

This is an impedance scan, not a harmonic-compliance check. It assumes a balanced per-phase equivalent circuit and ideal synthesized R/L/C values. It does not yet calculate harmonic current injection, THD, component RMS/peak stresses, losses across a spectrum, or standards status. The caller must supply a justified source impedance; the API does not invent one.

The new regression target checks logarithmic and linear scans, resonance-peak detection, and invalid input rejection.


## Balanced harmonic response and component stress

The filter module exposes `analyzeHarmonics(HarmonicAnalysisRequest)`. The caller supplies a per-phase RMS positive-sequence Thevenin voltage spectrum (including exactly one fundamental entry) and the per-phase source R-L impedance.

For each supplied harmonic order, the calculation:
- evaluates the source and each ideal series-RLC branch impedance at that harmonic frequency;
- solves the per-phase voltage divider between source impedance and the shunt filter bank;
- reports source/PCC voltage, filter current, and source current magnitudes;
- calculates bus-voltage THD and source-current THD relative to their respective fundamental components;
- aggregates each branch's RMS current and capacitor, reactor, and damping-resistor RMS voltage across the supplied spectrum;
- sums damping-resistor active loss as the sum of harmonic I²R terms.

For Delta-connected banks the balanced per-phase Y-equivalent is used for the network solution, while physical Delta branch current is converted back for component stress calculations.

This is a steady-state, balanced positive-sequence harmonic calculation. It does not model negative/zero sequence, unbalanced loads, neutral current, frequency-dependent source impedance, capacitor ESR/ESL, reactor core losses/saturation, thermal derating, transient behavior, or standards limits. The spectrum and source impedance must be supplied from a justified study or measurement. THD and stresses only cover the supplied harmonic entries; omitted orders are not assumed to be zero in a compliance sense. No PASS/compliance status is produced.
