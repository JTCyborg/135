# P135.005 — Power-quality and filter-performance plots

Status: desktop plots are connected to the current electrical and construction-bound magnetic calculation results. SYS-01 includes source-only reference, impedance-amplification bands, canonical harmonic markers and explicit series-tuning markers (including fractional tuning). Marker and band data are persisted with the calculation snapshot. Fundamental-only operating points are shown explicitly; missing non-fundamental inputs remain visibly NOT_PROVIDED rather than being synthesized. Several advanced solver-dependent plots remain unimplemented.

## Design rule

The Results workspace is split into two independent engineering groups:

1. **System / network performance** — whether the filter changes PCC impedance, attenuates injected harmonic currents, and improves the voltage/current spectrum without creating resonance amplification.
2. **Component performance** — whether the reactor core, windings, capacitors and damping elements remain within electrical, magnetic and thermal limits.

A plot is a view of a calculation artifact, not an independent solver. It must retain its input revision, model assumptions, units, and status. Missing inputs produce WAITING_FOR_INPUT or NOT_VERIFIED; no synthetic curve is substituted.

## SYS-01 — bus impedance comparison

The current frequency response returns filter-bank, source Thevenin and source-parallel-filter impedances. The desktop chart now presents:

- `|Z_bus(f)|`: `|Z_source || Z_filter|` when source R/L is present;
- `|Z_grid(f)|`: source Thevenin magnitude without the filter, as a dashed reference;
- candidate parallel-resonance peaks and their -3 dB bands from the existing scan.

If source R/L is zero, the UI shows only the filter-bank diagnostic curve and explicitly does not call it a source-limited bus impedance or a grid resonance study. This is a balanced per-phase Thevenin equivalent; it is not a detailed feeder/transformer frequency-dependent network model.

## SYS-02 — harmonic current transfer

For each explicitly supplied non-fundamental load-current injection with non-zero magnitude, the desktop chart plots:

`K_I(h) = |I_{grid,h}| / |I_{load,h}|`

The horizontal unity reference is 1 pu. Values below one mean the calculated source current magnitude is below the injected load-current magnitude; values above one indicate amplification in this model. Canonical orders (3, 5, 7, 11, 13, 17, 19, 23, 25) are marked when present in the supplied spectrum.

Important limitations:

- This is a magnitude ratio, not a complex transfer function and not a general frequency-continuous transfer curve.
- Only orders explicitly present in the input spectrum are plotted. An absent order is not interpreted as zero.
- The current source result includes the supplied background harmonic voltage and all matching load injections. The ratio therefore describes the actual solved operating point, not a source-independent filter attenuation constant.
- A zero load-current harmonic has no defined ratio and is omitted.
- No standards-compliance status is inferred from this graph.

The samples are also stored in the calculation result snapshot under `harmonicCurrentTransfer`.

## Plot readability and engineering interpretation

The shared desktop plot renderer now applies the following presentation rules:

- Line charts use a padded data-driven Y range instead of forcing every positive-valued response to start at zero. Bar charts retain a zero baseline; signed waveforms retain both polarities.
- Major horizontal and vertical grid lines are drawn behind the data. Logarithmic frequency axes keep logarithmic tick placement.
- Legends wrap onto additional rows rather than running off the right edge when several phase/section series are present.
- Each populated plot reports sample count and the displayed X/Y data ranges in its header. This is a data-range diagnostic, not a substitute for the physical unit printed on the axis.
- The PCC voltage spectrum includes a 100% fundamental reference level. The current-transfer plot retains its explicit unity (1.0 p.u.) series and canonical harmonic markers.
- Existing resonance bands, harmonic-order markers and entered magnetic-current criteria remain separate from calculated data series.

These presentation changes do not add missing solver outputs. In particular, a visually complete chart is not proof of model validity: missing inputs remain visibly gated, and no IEC/IEEE/GOST limit is drawn until a versioned assessment profile and its applicability inputs are supplied.

## Standards assessment

IEEE 519, ГОСТ 32144 and the applicable IEC 61000 parts must be represented as versioned assessment profiles, not a universal horizontal limit. The profile must retain edition, PCC voltage class, short-circuit ratio or other required network context, individual harmonic limits, THD/TDD definitions, aggregation interval and applicability conditions. A threshold must not be drawn until all inputs required to select that threshold are present. A standards result must be separate from the underlying physical waveform/spectrum calculation.

## Acceptance requirements

- Every series identifies the physical quantity, phase/sequence basis, RMS or peak convention, unit and source revision.
- Curves from different physical quantities are never substituted for each other.
- Before/after curves use the same network and load inputs; only the filter state changes.
- The plot displays WAITING_FOR_INPUT / NOT_VERIFIED / VALID / FAILED and a reason where appropriate.
- No compliance PASS is generated from an incomplete harmonic spectrum or an unqualified standard threshold.
- Debug PNGs and persisted plot data are reproducible from the same calculation revision.
