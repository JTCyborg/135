# P135.001 — Desktop UI shell

Status: initial Qt Widgets shell implemented; not a production engineering application yet.

## Included

- Windows desktop executable target: `Project135`.
- Qt 6 Widgets main window with Project, Filter definition, Calculation and 3D CAD pages.
- Initial project identity and product-family selection.
- Draft input controls for shunt filter topology, nominal line voltage, fundamental frequency and target reactive power.
- Session activity log and explicit messaging that draft inputs are not calculated results.
- Core and Circuit libraries linked without adding Qt dependencies to their public APIs.

## Not yet implemented

- Persistent project files, SQLite repository and revision history.
- Full engineering domain model and validated input schema.
- Filter synthesis and connection-aware three-phase circuit construction.
- Harmonic spectrum editor, source impedance and resonance evaluation.
- Material database, magnetic/winding/thermal calculations.
- OCCT viewport, geometry generation, drawings and exports.
- Standards checks, reports and optimization.

The Calculate toolbar action is intentionally guarded and does not claim to produce engineering results. The initial UI is a navigable application shell and input-form prototype only.
