# P135.001 — Desktop UI

Status: Qt Widgets desktop application shell with the first connected engineering workflow.

## Included

- Windows desktop executable target: `Project135`.
- Qt 6 Widgets main window with Project, Filter definition, Calculation and 3D CAD pages.
- Project name and product-family selection.
- Connected input form for the first supported product: three-phase shunt passive harmonic filter.
- Inputs: RMS line-to-line voltage, fundamental frequency, Wye/Delta connection, total three-phase target reactive power, tuning harmonic order and branch quality factor.
- Calculate toolbar action and form button call the Qt-independent `Project135Filter` synthesis API.
- Results table displays phase RMS voltage, capacitance, inductance, series damping resistance, tuning frequency, target reactive power and quality factor.
- Invalid inputs are shown as explicit errors; no result table is populated for failed synthesis.
- The UI blocks calculation for product families that are not implemented yet.
- Activity log and explicit limitations message.

## Current calculation boundary

The desktop currently runs analytical ideal-component sizing for parallel single-tuned series-RLC branches. It does not yet calculate capacitor/reactor ratings, network impedance, harmonic spectrum, resonance interaction, component losses, thermal performance or standards compliance. Results are preliminary sizing outputs, not a complete filter design approval.

## Not yet implemented

- Persistent project files, SQLite repository and revision history.
- Multiple editable branch collection in the UI (the current form creates one branch per calculation).
- Three-phase circuit topology generation and verification through Project135Circuit.
- Harmonic spectrum editor, source impedance, resonance and THD evaluation.
- Material database, magnetic/winding/thermal calculations.
- OCCT viewport, geometry generation, drawings and exports.
- Standards checks, engineering reports and optimization.

The CAD page remains a placeholder. Geometry will be generated from the engineering domain model; CAD will not be the source of electrical parameters.
