# **Сценарий проверки Project135 — TEST-01**

Проверяем полный путь от создания проекта до результатов расчёта, предварительного проектирования реактора и формирования 3D CAD.

**Цель:** убедиться, что электрический синтез LC-фильтра работает, исходные данные передаются в расчёт реактора, отсутствующие физические параметры не подменяются догадками, а неподтверждённая конструкция не допускается к выпуску.

[Fedezze fel az EcoStruxure™ Power Design szoftvert](https://images.openai.com/static-rsc-4/-WlYc1HywR9j9yTWRavRpD8ElbnG4m5JuvE3g8UosAB2GVzpty6Cv0v5LjRd2XZ5I80relu6C8DAHhyqB9fcq9wrV6rSq9_xfxARRULwiINTcAkb3d-TMUUJh6c26tBh8zQaUZKCHYLwyJbYOzQAMlxp6_IxlUwjVxHX4DMMV2M?purpose=inline)

Открой приложение Project135.

1. Перейди на вкладку **Project**.
2. Создай новый проект либо открой TEST-01.
3. Проверь, что проект загружен без ошибок.
4. Убедись, что отображается правильное название проекта.
5. Проверь, что нет ранее принятых физических или CAD-ревизий, которые могли бы повлиять на результаты.

Ожидаемый результат:

- проект открыт;
- исходное состояние корректное;
- неподтверждённые параметры не отображаются как готовая конструкция.

## **3. Окно Construction — параметры конструкции**

[Dry-Type Iron-Core Reactor (Low Voltage) | Reactor manufacturer](https://images.openai.com/static-rsc-4/3j4GrijZpZ5lRgO3fD0ewde5786qK0ddjeyOm94UST0bOWQeY59TM0ooAPIXAdSlCMGLuzL5Mb5dSvXkVvZS9D2R0WpTVbImSIpz9aGLXHADJdqjH38MDSgBcnktx7JbXAN3--3djlSfdHHyBokavi1difK9u9fLRHnoSzmw274?purpose=inline)

Проверь:

1. Выбран ли тип магнитопровода.
2. Можно ли задать трёхстержневую конструкцию.
3. Есть ли параметры материала магнитопровода.
4. Есть ли параметры обмоток и охлаждения.

На этом этапе не нужно принимать неподтверждённую геометрию.

Ожидаемый результат:

- отсутствующие параметры отмечены как `NOT_PROVIDED` или `NOT_VERIFIED`;
- размеры магнитопровода не выдаются за рассчитанные.

## **4. Окно Calculation design — электрический и физический расчёт**

[What information is available in the Results panel for load circuits and feeder circuits in EcoSet Design? | Schneider Electric España](https://images.openai.com/static-rsc-4/5w4hBnOBCedan4iaeGi8pk_Jl7oTUgLlYGnx0Kap0Ck21c5Vvr3ZUs8tc7arrdBVmauvQ-XPCg9a608fctn9cr3zAPMrfOZQIOVvQfItIVzbPDmQFQxypgMTFSjk9J862NCir4kNRuzz39Wk8RzN7kceLfxFfwkCti3DB2KLQYI?purpose=inline)

Это основное окно проверки.

Найди результаты синтеза фильтра и проверь следующие контрольные значения:

| Параметр                    | Ожидаемое значение |
| --------------------------- | ------------------ |
| Фазное напряжение           | 230.9401 V         |
| Ёмкость фазы                | ≈ 1.910 mF         |
| Индуктивность фазы          | ≈ 0.2122 mH        |
| Сопротивление демпфирования | ≈ 6.667 mΩ         |
| Фазный ток                  | ≈ 144.338 A RMS    |

Далее проверь пять критериев физического расчёта реактора:

- `Bmax` — допустимая индукция;
- `J` — плотность тока;
- `Ku` — коэффициент заполнения окна;
- `Ks` — коэффициент шихтовки;
- `Aw/Ae` — отношение площади окна к площади сердечника.

Для тестового предварительного расчёта использовались:

| Критерий | Тестовое значение |
| -------- | ----------------- |
| Bmax     | 1.2 T             |
| J        | 3 A/mm²           |
| Ku       | 0.35              |
| Ks       | 0.95              |
| Aw/Ae    | 2.0               |

Это тестовые допущения, а не подтверждённые характеристики выбранного материала и технологии изготовления.

Нажми **Recalculate project**.

Ожидаемый результат:

- электрические параметры пересчитываются;
- запускается предварительная оценка area product;
- расчёт показывает свои допущения;
- результат маркируется `PRELIMINARY` / `NOT_VERIFIED`;
- CAD-релиз остаётся заблокированным.

Проверь:

1. Создаётся ли 3D-модель.
2. Отображаются ли стержни, ярма и обмотки.

## **6. Окно Materials database — проверка материалов**

Проверь наличие:

- электротехнической стали;
- B-H характеристик;
- удельных потерь;
- данных по температурным характеристикам;
- данных по проводникам обмоток.

Необходимо отличать реальные паспортные характеристики от тестовых или отсутствующих данных.

## **7. Окно Calculation history — проверка истории**

Проверь:

- сохраняется ли факт пересчёта;
- фиксируются ли входные параметры;
- сохраняются ли результаты;
- отображаются ли ревизии;
- аннулируются ли устаревшие результаты после изменения исходных данных.
